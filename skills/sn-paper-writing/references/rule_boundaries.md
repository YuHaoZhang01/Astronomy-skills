# 规则证据的范围与反向检查

本表是对结构性观察的匿名汇总；不是逐篇证据公开，也不复述任何论文发现。原文与逐段来源账本由语料所有者在本地保管，不随技能发布。公共使用者可执行这些规则，但无法仅靠本包独立复核原来的全文覆盖。

反例针对一刀切的强读法，未必反驳收窄后的规则；范围限制也不等于否定。某模式没有被选为证据，不代表全文不存在。

| 规则 | 支撑的组织方式 | 反例或范围限制 | 裁决 |
|---|---|---|---|
| R01 问题收束 | 背景与已有用途收束到具体问题。 | 摘要也可直接方法或样本开场，局部问题收束也在正文出现。 | 按章节上下文使用，不强制每个开头都有独立背景句。 |
| R02 贡献与继承分开 | 贡献用连续研究动作表达，扩展稿区分继承与增量。 | 增量定位可分布在方法正文；编号往往用于参数或阶段。 | 不固定数量、位置或编号，不把任务声明直接当创新。 |
| R03 文献参与论证 | 引文用于界定问题、说明假设、归属方法和应用对照。 | 存在独立技术比较章；来源归属型引用并不都批评前人。 | 保留功能性引用原则；没有选出直接反例不等于每条引文都准确充分。 |
| R04 导航按阅读需要设置 | 长文引言有章节及证据分工导航。 | 短个例可无逐节路线图；正文也可重新给局部导航。 | 按阅读需要设置，不能从多数样本推出全稿型硬要求。 |
| R05 方程有上下文，段首顺序灵活 | 许多推导由目的、系统或示意图引入。 | 定义开头、积分开头和连续操作型推导同样存在。 | 保留章节级上下文；废弃每个公式段必须物理先行。 |
| R06 前提与使用位置邻接 | 关键前提、默认值及可能影响贴近使用位置。 | 可选处理只作短提示；沿用已明设置时可只指出改变项。 | 重要变化处邻接说明，不在每句话重述全套假设。 |
| R07 按论证任务组织图文 | 比较设置、图中行为、解释与条件能形成完整论证链。 | 有主张先行、机制先行，也有相邻两段分别展开比较两侧。 | 废弃固定四步段序，以任务及可追溯性约束组织。 |
| R08 检验名称与证据对应 | 有加密、方法交叉、删项控制、先验变化、退化检查等不同检验。 | 后验窄或单峰不独自证明收敛；算法描述不等于做过加密；重叠指标不等于假设检验。 | 按真正执行的操作和支撑对象命名，不能泛称全面稳健。 |
| R09 断言强度随证据层级变化 | 解释常伴随范围、替代可能、先验依赖和有效量限定。 | 有限比较范围内也有直接强判断；有些推广段的承诺强于附近证据。 | 不一律加强或弱化；观察到强措辞不等于推荐。未拒绝不能改成证明。 |
| R10 主文与附录按功能分层 | 主文给关键论证，附录展开推导、实现或完整样本。 | 也有无附录稿件，主文直接说明实现与数值检验。 | 分工按稿件需要，不强制移走数学和验证材料。 |
| R11 时态和语态按动作功能选择 | 作者研究动作、模型／图主语和被动设定按功能交替。 | 方法可用现在时，同段可有过去操作与当前判断。 | 语态、时态由语义决定，不作整章机械替换。 |
| R12 结尾回收证据并保留边界 | 结尾回收贡献、证据和范围，具体未决任务与边界相连。 | 有必要关系或数值重述，也有合并讨论结论中的进一步图示讨论。 | 允许不同结尾形态；压缩空重复，不绝对禁重复或未来工作。 |

## 通用模板的冲突

- 一段一主任务不等于一句主张加一句证据；连续推导、多条件比较和限制清单可以有多个修辞动作。
- 必要的提醒、综合和问题句有功能，不用禁词表代替逻辑判断。
- 摘要长度是语料描述，不能代替正式投稿指南。
- 图表、后验、拟合优度、数值诊断与物理机制的证据等级分别核对。
- 主要样本和范文的作者相关性高，重复次数不等于独立证据强度，不是整个期刊的规范。

新增语料时重新核查支持、反例和边界；更新方法见 [distillation.md](distillation.md)。
