# 段落推进与论证衔接

箭头表示逻辑依赖，不要求每格恰好一段。这里提供修辞动作，不提供可替换对象名称的范文句子；事实、公式、证据和解释必须来自用户材料。

## 可迁移的组织动作

| 模式 | 前段留下什么 → 本段做什么 → 后段接什么 | 使用边界 |
|---|---|---|
| 承认用途再界定缺口 | 已有方法价值 → 特定前提或用途下的不足 → 对应研究动作 | 不凭空贬低既有研究或制造缺口 |
| 目的引出处理 | 需要获得或比较的量 → 必要操作 → 解释产物或检验 | 上下文已有目的时可直接进入定义 |
| 连续定义与求解 | 既有记号 → 变换／求解 → 代入、特例或验证 | 不为每段主张先行打断推导依赖 |
| 基准—改变—解释 | 匹配设置 → 改变项 → 差异及适用条件 | 关联变化不能自动写成隔离归因 |
| 共同点—分叉—对照 | 复用共同设置 → 不同条件分支 → 共性及例外 | 不要求两分支同样长，也不要求每段复述基准 |
| 阶段阈值推动 | 上一阶段状态 → 阈值或边界改变 → 新阶段处理及后果 | 物理时间、计算次序和叙述顺序须区分 |
| 主张先行 | 任务已明确 → 先概括关系 → 图、比较和条件展开 | 概括必须来自已有证据，不是所有结果段的唯一结构 |
| 机制先行 | 前段报告行为 → 从已有机制解释 → 图或条件分支核对 | 不为顺序完整补造机制 |
| 两段完成比较 | 首段展开一侧 → 次段展开另一侧 → 对照闭合 | 第二段要有明确回指，避免被读成独立无关结果 |
| 经验层转模型层 | 定义测量及分母 → 经验空间 → 共同建模任务 → 模型空间回接 | 切换时说明量从何而来，经验相似不等于物理同源 |
| 疑点触发检查 | 先验边界、退化或偏差 → 针对性检查 → 调整相应判断范围 | 没做的检查不能写成已经完成 |
| 限制产生下一任务 | 当前依赖 → 受影响的推断 → 所需信息或下一步 | 保留具体未决性，避免泛泛展望 |

## 衔接选择

| 实际关系 | 表达动作 | 核对要点 |
|---|---|---|
| 前提已建立 | 回指方程、设置或基准，只补改变项 | 回指对象必须唯一 |
| 有共同点也有差别 | 先复用共同项，再说明分叉条件 | 转折不应无意否定整个前段 |
| 条件导致不同结果 | 条件前置或紧贴对应分支 | 拆句后条件的作用域不能改变 |
| 描述进入解释 | 明示由观测／计算输出转入模型判断 | 时间先后不能代替因果证据 |
| 例外收窄概括 | 总体判断后保留具体偏差，或先异常后主判断 | 一致性不能自动抹去反例 |
| 示例进入全样本 | 说明示例职责、全量证据位置和分母 | 图示代表性不是总体检验 |
| 结果引出新任务 | 由已有证据提出待回答问题 | 后文需要兑现任务，不能只有意图 |

## 按篇幅调整

长方法稿可让总图、分支推导、控制比较和应用分工；短个例可以围绕少量观测要求串起方法与检查。群体比较需要更清楚的样本层级和经验／模型层级切换。

短任务段、短定义段与长条件／推导段可以混用。长段内若有多个步骤但共同推进一个任务，不必机械拆分；若论据、主张或作用域发生变化，则考虑分段并补清回指。不能从某篇长文推导出其他稿件也必须增加背景或总结长度。
