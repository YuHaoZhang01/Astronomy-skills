# 写作规则与章节指导

## 规则优先级

原稿技术内容和用户明确约束优先。其次采用相关的语料内写作模式；主要语料缺少指导时补充相同稿型的领域或课题组模式；最后才使用一般写作默认。无信息表达的清理不能覆盖技术保真。

以下 12 条是全文分析后的可执行版本。规则号用于变更日志；证据边界和不应作出的强推断见 [rule_boundaries.md](rule_boundaries.md)。

| 规则 | 可执行指导 |
|---|---|
| R01 问题收束 | 引言把已有背景收束到具体问题，再说明本文动作；摘要或已获上下文的正文可直接进入方法、对象或局部任务，不补造缺口。 |
| R02 贡献与继承分开 | 用具体研究动作说明原稿已有的贡献，同时标清继承部分；不固定数量、段落位置或编号。不把参数、阶段或样本筛选列表误当作贡献清单。 |
| R03 文献参与论证 | 围绕问题、假设、方法差异或来源归属组织原稿已有引文；需要较长技术比较时允许专章。保留引文及支持关系，不凑密度，不把来源说明强改成优先权或批评。 |
| R04 导航按阅读需要设置 | 长篇或多分支稿件可简述各节任务和证据分工；短个例按需要省略。正文进入新分析层次时可用短任务段或回指，避免机械重复摘要。 |
| R05 方程有上下文，段首顺序灵活 | 在章节或相邻段落交代方程的任务、必要前提和含义；上下文已足够时，段落可从定义、假设、代入或推导动作开始。符号解释与条件就近保留，不为每个公式重复补写动机。 |
| R06 前提与使用位置邻接 | 关键前提在首次使用、改变或推断依赖它时就近说明；沿用明确设置时可回指。保留默认值、例外、选择理由和解释边界，缺失依据只提问题，不自行补写。 |
| R07 按论证任务组织图文 | 围绕一个清楚的比较任务组织图文；允许设置先行、主张先行、机制先行和跨段对照。保证必要设置可追溯、解释来自原稿、边界可见，不要求每段重复所有环节。 |
| R08 检验名称与证据对应 | 准确命名原稿实际完成的检验，并写清比较对象、改变项、观察量与适用范围。拟合优度、参数约束、采样诊断、数值收敛和机制识别分开；不得新增测试或把一种证据升级为另一种。 |
| R09 断言强度随证据层级变化 | 区分直接比较、模型内推断和解释性外推；前者可直接陈述，后两者保留原有条件、退化和不确定性。不因润色升级确定性，也不无故削弱已支持判断。 |
| R10 主文与附录按功能分层 | 主文保留理解与评价论证所需的设定、关键公式和检验；附录可承载较长推导、实现或完整样本。按稿件需要分工，未获内容重组授权时只建议，不移动技术材料。 |
| R11 时态和语态按动作功能选择 | 作者承担选择、计算、比较等研究动作；系统、模型或图表承担行为陈述；定义与处理可用被动。现在时可讲框架和当前结果，过去时可讲完成的操作，按实际语义保留，不能整章统一替换。 |
| R12 结尾回收证据并保留边界 | 可合并讨论结论，也可独立收束；回收关键贡献、证据与边界，保留服务于综合或使用的必要重述和具体未决任务。压缩无信息重复，不新增结果，不按统一段数或字数裁切。 |


## 按稿型补充

| 稿型 | 主要组织任务 | 必须保留的区分 |
|---|---|---|
| 理论或数值方法 | 问题及前提 → 形式化 → 受控比较 → 应用及范围 | 模型性质、数值支持、一般证明不是同一层 |
| 框架扩展 | 继承部分 → 本次实际增量 → 耦合或实现 → 相应检验 | 集成工作的增量与单组件的新颖性分开 |
| 光变拟合 | 数据与约定 → 固定及自由参数 → 推断程序 → 拟合与参数 → 条件化解释 | 拟合优度、后验约束、采样诊断和物理识别分开 |
| 群体比较 | 母样本及子样本 → 经验测量空间 → 共同模型 → 参数空间 → 退化与选择效应 → 解释 | 测量量、拟合量和派生量，以及每次比较的分母 |
| 简短个例 | 诊断价值 → 观测要求 → 基线及扩展 → 控制对照 → 剩余问题 | 示例职责与代表性、有效诊断与唯一机制分开 |

只采用与原稿实际工作对应的路径；不为了套结构补模型、检验或数据。

## Abstract

交代已有的问题或对象、方法、主要已支持结果和适用范围。框架稿或样本稿可直接进入研究工作，无须机械补独立背景句。现在时和过去时按功能选择；不固定句数、贡献条数或 150–250 词。正式字数和格式限制应依据用户目标期刊的最新指南另行核对。

避免只有意图而没有原稿已有结果；不凭空量化、不删关键条件，不复用参考文章的结论。

## Introduction / Literature Positioning

让现有材料由背景收束到具体缺口。先承认既有方法的实际用途，再说明在哪些前提或任务下需要新处理。用具体研究动作定位贡献；不固定贡献的段落位置和条数。

按问题、假设、方法差异或来源归属组织已有引文；不逐篇摘要，也不强迫每条引文都批评前人。必要的长方法比较可以专章。长文可给简短功能路线图，短个例按阅读需要决定。

## Methods / Model

章节或相邻段落建立任务、系统和前提。局部可从定义、假设、代入或求解开始；保持公式附近的符号说明、条件和解释。不要为每个公式重复物理动机。

阶段切换时说明继承、终止和新增了什么。方法扩展时区分沿用组件与真实增量。拟合程序保留数据选择、观测系、时间零点、固定与自由参数、先验、似然和区间定义。缺失细节只提示作者，不编写成已实施的步骤。

主文保留理解与评价所必需的设定、公式及检验，附录可容纳长推导、实现或完整样本；不强制另设附录。

## Results

围绕比较任务组织图文，可以设置先行、主张先行或机制先行，也可跨相邻段落完成双方对照。复用明确的基准，只展开改变项。总体行为与具体偏差可以并陈；已有解释的位置可以调整，内容不能新增。

检验名称取决于实际做了什么：

| 工作 | 能直接支撑的判断 | 不能自动替代 |
|---|---|---|
| 网格或时间步加密 | 对所报告输出的数值变化检查 | 所有尺度均已解析或模型物理正确 |
| 匹配设置下的方法比较 | 近似或求解方案的差异范围 | 对自然界的唯一解释 |
| 删除组件的控制比较 | 该设置下组件的作用 | 所有替代模型均被排除 |
| 放宽先验或改变结构 | 对该先验／结构选择的敏感性 | 无先验依赖或参数唯一识别 |
| 协方差分解 | 对具体退化解释的核查 | 普遍无偏性 |
| 重采样与带宽变化 | 指标不确定性及特定估计选择的影响 | 正式零假设检验 |
| 采样诊断 | 按其准则评价链行为 | 拟合好坏、完整稳健性或物理正确性 |
| 模型选择准则／统计检验 | 准则或零假设设定内的比较 | 由未拒绝推成机制同源证明 |

后验窄、单峰、图像相似、实现描述或描述性重叠不能单独替代这些检验。只报告原稿实际完成的工作。

## Discussion

从已报告证据转到有条件的意义；标明从直接比较进入模型内推断或观测外推的切换。保留选择效应、观测覆盖、先验、有效参数与替代机制的影响。不要将共同参数化等同于统一物理起源。

限制要说明依赖什么、影响哪项判断、什么新信息有助于区分；可先分项再指出最相关的限制。不用泛泛的道歉清单替代具体范围。

## Conclusion

允许合并讨论结论，也允许独立收束。回收关键贡献、相应证据与边界；保留服务于综合或实际使用的必要公式／量化回顾和原稿已有进一步讨论。压缩没有新增功能的重复，不统一裁成固定段数。

具体未来任务应接到现有未决问题。结尾可以保留剩余偏差，不为显得完整把它写成已经解决，也不添加新结果。

## 按功能清理语言

优先清理空泛意图、没有信息的提醒语、空转并列、重复价值评价和泛泛未来口号。提醒、综合、转折和未来时都可能承担真实的条件或证据功能，不能按词表盲删。

一个段落有一个清楚主任务即可包含定义、比较、条件与限制。功能性问题可引出后续分析。没有句长、被动率或连接词配额。
