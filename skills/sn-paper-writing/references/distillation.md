# 从用户本地语料更新写作习惯

仅在用户要求新蒸馏、追加语料或改变写作目标时使用。本包的已有规则可以直接用于写作，无须参考原文作为运行依赖。

## 输入与角色

沿用用户已给的目标、论文路径和稿型。将主要目标语料、补充领域语料和课题组范文分开；出版身份不明时保留不明状态。检查作者和方法的相关性，不能把多篇合作论文当作互相独立的期刊样本。

只缺影响工作的输入才询问；无需为了填满模板再收集已经知道的信息。把原始论文和证据账本保存在用户研究项目，不复制进 skill 文件夹。

## 全文可读性与分组

使用本地可用工具取得阅读副本。检查双栏顺序、跨页续段、标题、链接叠字以及图表遮罩误吞正文。文字和公式有疑问时回原 PDF 页面或请求可靠源稿，不猜写缺失内容。

明确计数对象：摘要、正文叙述、有文字的附录；独立公式、图表单元格、图注、脚注、参考文献和版面元素另标。用户要求分析这些额外材料时，另列范围，不混淆覆盖声明。

重建单元可能拆开原段或合并列表。为单元保留稳定 ID、页码和来源位置；合并、拆分、排除要可追溯。报告重建单元与复核叙述组两个计数，不冒充排版段落的精确普查。

## 逐段阅读与标注

逐篇读完声明范围内的全部叙述；不能只看摘要、引言和结尾后宣称全文完成。分批阅读时记录已完成区间，输出截断的部分必须补读。

每个叙述组至少保存：

| 字段 | 内容 |
|---|---|
| ID 与来源 | 论文角色、章节、PDF 页序或可靠文本位置 |
| 段内推进 | 按实际出现顺序记录问题、定义、设置、比较、解释、限定等动作 |
| 句式与主语 | 作者动作、系统／图主语、被动、条件、对照、定义、时序等实际功能 |
| 承上启下 | 使用前段什么信息，本段留下什么给后段 |
| 规则关系 | 支撑、强读法反例、范围限制，或未选作裁决证据 |
| 状态与边界 | 已读／待核、合并成员、拆分理由或排除理由 |

标注只写结构与修辞，不摘录、改写或复现科学发现。自动词频或关键词匹配可辅助定位，不能冒充逐段语义阅读。代码计数是组级记录，不是被动句百分比或独立统计样本数。

## 逐条规则裁决

对每个候选规则明确可检验的强读法，然后寻找支持它的段落及有意的反向案例。记录查找范围、证据 ID、反例／边界、最终判定以及可执行措辞。

没有找到反例时说明实际搜索范围；不要编造反例，也不要把未观察到升级成通用禁令。根据稿型、章节、证据层级或上下文收窄规则，优先保留能帮助决策的差异，避免积累模板配额。

汇总逐篇篇章路径、跨篇共同动作及不同稿型的变体。标题、作者和卷期属于内部来源元数据，科学结论不进入技能规则。一般写作默认与实际语料冲突时明确裁决，技术保真始终优先。

## 完成与交付

核对全部声明纳入的单元恰好覆盖一次、组数一致、证据 ID 与来源链接可解析。保留原件；把目视复核、数学核验、语法统计和科学审稿的实际范围分别报告，不能互相替代。

交付动态规则、段落与句式画像、逐条裁决和本地覆盖记录。未读区间或不可读材料存在时明确剩余范围，不报全文完成。只有用户要求修订时才将规则用于稿件。

若用户要求公开 skill，只构建明确列出的规则与使用文件。逐段账本、来源清单、论文副本、图像、转换缓存和用户本机路径继续留在研究项目；发布前检查确切文件列表和文本，不把整个工作目录打包。授权发布技能不等于授权公开论文。
