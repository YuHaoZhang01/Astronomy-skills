# 句式偏好与主语分工

这些选择服务于论证功能，不是语态比例、连接词词频或固定范文句型。

| 维度 | 使用方式 | 避免 |
|---|---|---|
| 作者主语 | 承担选择、定义、计算、比较、导航和回顾 | 每句都加作者，或用抽象价值词代替具体动作 |
| 系统／模型／图表主语 | 陈述过程行为、形式性质和图中关系 | 用模型能力宣称替代实际证据 |
| 被动语态 | 交代设定、输入、数据处理和求解；施事不是信息重点时保留 | 整稿统一改主动或擅自添加施事 |
| 定义和操作句 | 定义从句、条件设定、代入／重排等分词结构可连接推导 | 每次定义前重复高层背景 |
| 条件句 | 将前提放在句首、限制性从句或结论附近 | 拆句时扩大结论范围、漏掉例外或否定 |
| 对照／让步句 | 先用途再限制、先相同再分叉，或总体判断后具体偏差 | 用转折把前段全盘推翻；强求两侧同样长 |
| 可能性限定 | 机制归属、外推、退化和未知性处保留真实不确定性 | 一律弱化直接比较，或靠情态词掩盖缺失证据 |
| 列举 | 参数、阶段、筛选条件和分项限制要由引导句定义功能 | 把所有列表当贡献清单 |
| 时间表达 | 区分物理阶段、实施步骤与章节回顾 | 把先后关系写成已经验证的因果 |
| 时态 | 当前框架、图示和概括可用现在时；已实施工作可用过去时，同段允许混用 | 方法或摘要整章一律过去时 |
| 句长与问题句 | 短任务句与必要长条件句并用；真实问题可引出分析 | 固定词数阈值、绝对禁问句 |

## 修改时的顺序

先确认本句承担的动作以及它与前后句的关系，再选择主语、动词、时态和连接方式。拆开长句时先标明条件限制了哪个主张，保留其作用域；合句时不要让原本有不同条件的结论共享一个不恰当的前提。

直接比较、模型内参数判断与解释性外推可以在一段内相接，但强度应随证据转换。明确条件不必然等于使用可能性情态，可能性情态也不能替代具体前提。

提醒词、总结词和未来时有时承担范围限定、回指和新任务安排。只清理没有实际作用的部分；不对全文做禁词替换，不触碰脚注或其他原样保留的技术材料。

## 观察的边界

蒸馏时的句式代码只表示叙述组里被记录的功能，可多标；没有做可靠的逐句语态普查、连接词频榜或句长分布。不同稿型、篇幅和附录比例也会影响出现次数。因此不规定主动率、限定语密度或某位作者专属句型。
